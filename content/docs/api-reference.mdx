Base URL `https://cambill.cubis.tech`. Send your key in `X-API-Key`. The machine-readable description is [openapi.yaml](https://cambill.cubis.tech/v1/openapi.yaml). Amounts are integers in the minor unit. Errors are [problem+json](/docs/errors).

## Subscriptions

### Subscribe a customer to recurring prices

`POST /v1/subscriptions`

Bills the customer by invoice each period, in advance. The first invoice is created now; each is issued automatically unless `auto_issue` is false. Nothing is charged: the customer pays each invoice from its link. All items must share one currency and billing interval.

| Field | Type | Required | |
| --- | --- | --- | --- |
| `customer` | string |  |  |
| `customer_external_id` | string |  |  |
| `items` | object[] |  |  |
| `days_until_due` | integer |  |  |
| `auto_issue` | boolean |  | Issue each invoice as it is created |
| `cancel_at_period_end` | boolean |  |  |
| `coupon` | string |  | A coupon id or code, on create. It discounts the periods its duration covers (once, N months, forever) and is used up once, by the first invoice. |
| `metadata` | object |  | Up to 20 keys (`a-z 0-9 _ . -`, 40 characters); values are plain text up to 500 characters. |

Returns `201` created. Errors: `400`, `403`.

### List subscriptions

`GET /v1/subscriptions`

Filters combine (all must match). An id or external id that matches nothing gives an empty list, not an error.

| Parameter | In | Type | |
| --- | --- | --- | --- |
| `page` | query | integer |  |
| `limit` | query | integer |  |
| `customer` | query | string | A customer's CamBill id. |
| `customer_external_id` | query | string | Your own id for the customer. |
| `product` | query | string | A product's CamBill id: subscriptions with an item for any of its prices. |
| `product_external_id` | query | string | Your own id for the product. The usual way for another system to pull its subscriptions. |
| `price` | query | string |  |
| `coupon` | query | string | A coupon id or code |
| `status` | query | `active` \| `paused` \| `canceled` |  |
| `expand` | query | `customer` \| `items` \| `customer,items` | `customer` and/or `items`: the same full object webhooks carry (`customer_details`, and items with their price and product). |

Returns `200` ok.
